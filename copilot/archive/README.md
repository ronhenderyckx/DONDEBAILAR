# Archief

Bewaar hier afgeronde opdrachten en de bijbehorende resultaten.

Gebruik per taak herkenbare, unieke bestandsnamen, bijvoorbeeld:

- `opdracht-2026-11-17-workflowcontrole.md`
- `resultaat-2026-11-17-workflowcontrole.md`

Kopieer de actieve opdracht en het bijbehorende resultaat naar het archief voordat de actieve bestanden voor een volgende taak worden overschreven. Overschrijf bestaande archiefbestanden niet.
